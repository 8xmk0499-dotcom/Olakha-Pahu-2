# 🎨 ओळखा पाहू! 👀 – Draw & Guess Battle

> **मराठी ऑनलाइन मल्टीप्लेअर पार्टी गेम**  
> चित्रे काढा, शब्द ओळखा आणि मित्रांसोबत धम्माल मजा करा!

---

## 🌟 वैशिष्ट्ये (Features)

- **🎨 अधिकृत नाव:** `🎨 ओळखा पाहू! 👀` (English Subtitle: `🎨 Draw & Guess Battle 👀`)
- **📱 मोबाईल-फर्स्ट डिझाईन:** 
  - Android आणि iPhone स्मार्टफोन्ससाठी विशेष अनुकूलित
  - टचस्क्रीन बोटाने गुळगुळीत रेखाटन (Smooth finger drawing)
  - स्क्रीन स्क्रोल न होता सुरक्षित ड्रॉइंग (`touch-action: none`)
  - नॉर्मलाइझ्ड कोऑर्डिनेट्स: ३६०px मोबाईल स्क्रीन ते ४K डेस्कटॉपपर्यंत कुठेही विकृती नाही
- **⏱️ ८०-सेकंद काउंटडाउन टाइमर:** 
  - प्रत्येक फेरीसाठी ८० सेकंदांची वेळ
  - ५० सेकंदांवर आपोआप पहिला संकेत (वर्ग व पहिले अक्षर)
  - २५ सेकंदांवर दुसरा संकेत (अजून अक्षरे उघड)
- **🖌️ चित्रकाराची साधने:**
  - पेन्सिल, ब्रश, खोडरबर
  - विविध जाडी (Thin, Medium, Bold)
  - १२ तेजस्वी रंग पॅलेट (Color palette)
  - Undo, Redo, आणि Clear Canvas
- **💡 स्मार्ट अंदाज प्रणाली (Smart Guessing):**
  - मराठी आणि इंग्रजी दोन्ही भाषांमध्ये ओळखता येते
  - स्पेलिंग जवळ असल्यास लगेच "🔥 खूप जवळ आहात!"提示 मिळतो
  - अचूक उत्तर ओळखल्यावर गुण मिळतात आणि इतरांपासून उत्तर गुप्त ठेवले जाते
- **👥 मित्र खोली (Multiplayer Lobby):**
  - ४ अक्षरी सोपा खोली कोड
  - एक-क्लिक कोड कॉपी
  - थेट व्हॉट्सअ‍ॅप (WhatsApp) आमंत्रण शेअर बटण
  - १२ रंगीबेरंगी अवतार
- **🌐 द्विभाषिक (Bilingual):**
  - डीफॉल्ट: मराठी (मराठी देवनागरी)
  - इंग्रजी (English) निवडण्याची सोय
- **🔊 वेब ऑडिओ ध्वनी प्रभाव:** 
  - कोणत्याही बाह्य ऑडिओ फाईल्सशिवाय झटपट लोड होणारे आवाज (टॉगल बटणासह)

## 🚀 स्थानिक पातळीवर सुरू करा (Quick Start)

```bash
# १. रेपॉझिटरी क्लोन करा किंवा फोल्डरमध्ये जा
cd "d:\Games\Olakha pahu"

# २. डिपेंडन्सीज इन्स्टॉल करा
npm install

# ३. गेम टेस्ट्स चालवा
npm test

# ४. सर्व्हर सुरू करा
npm start
```

ब्राउझरमध्ये उघडा: **`http://localhost:3000`**

## ☁️ Render वर डिप्लॉयमेंट (Render Deployment)

या प्रोजेक्टमध्ये `render.yaml` आधीच तयार आहे:

1. हा प्रोजेक्ट तुमच्या GitHub खात्यावर पुश करा.
2. [Render.com](https://render.com) वर जाऊन **New → Blueprint** निवडा.
3. तुमचे GitHub रिपॉझिटरी जोडा.
4. Render सर्व सेटिंग्ज (Node runtime, health check `/healthz`, port 10000) आपोआप वाचून गेम मोफत होस्ट करेल.

## 📁 फोल्डर रचना (Project Structure)

```
├── package.json          # Node.js कन्फिगरेशन आणि स्क्रिप्ट्स
├── render.yaml           # Render डिप्लॉयमेंट ब्लूप्रिंट
├── Dockerfile            # कन्टेनरायझेशनसाठी डॉकर फाईल
├── server/
│   ├── index.js          # Express + Socket.IO सर्व्हर
│   ├── game.js           # खोली व्यवस्थापन आणि गेम स्टेट मशीन
│   ├── words.js          # मराठी व इंग्रजी शब्दसंग्रह (Word bank)
│   └── test/
│       └── game.test.js  # ऑटोमेटेड युनिट टेस्ट्स
└── public/
    ├── index.html        # मोबाईल-फर्स्ट HTML इंटरफेस
    ├── style.css         # आधुनिक भारतीय पार्टी गेम स्टाईल
    ├── app.js            # क्लायंट लॉजिक आणि सॉकेट हँडलिंग
    ├── canvas.js         # रिस्पॉन्सिव्ह हाय-DPI कॅनव्हास इंजिन
    ├── audio.js          # वेब ऑडिओ ध्वनी प्रभाव इंजिन
    ├── i18n.js           # मराठी व इंग्रजी भाषा व्यवस्थापक
    ├── icon.svg          # कस्टम पेन्सिल, ब्रश व डूडल लोगो
    └── manifest.webmanifest # PWA मॅनिफेस्ट
```
